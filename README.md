# Wasm Arcade

**Play classic games in your browser:** https://wasmarcade.net/

Wasm Arcade is a free, no-login classic game library that runs in the browser. It lets you play the official Minecraft Classic online, try an open-source 2048 demo, load your own SWF files into a built-in Ruffle Flash player, and browse a curated index of 1,081 classic game entries.

## Collections

- [PC games](https://wasmarcade.net/categories/pc-games/)
- [Neo Geo](https://wasmarcade.net/categories/neo-geo/)
- [Capcom arcade](https://wasmarcade.net/categories/capcom-arcade/)
- [Arcade classics](https://wasmarcade.net/categories/arcade-classics/)
- [Flash games](https://wasmarcade.net/categories/flash-games/)
- [All 1,081 entries](https://wasmarcade.net/all-games/)

## How to start

1. Open [wasmarcade.net](https://wasmarcade.net/).
2. Pick a system on the home page, or use the search box to find a title.
3. Open an entry. Minecraft Classic needs a keyboard and WebGL.

No account, no install, no download.

## Notes

- The catalogue is an index. Each entry links to its source reference; the site does not host the original game files.
- Flash pages read a local SWF file inside your browser with Ruffle. The file is never uploaded.
- Wasm Arcade is an independent project and is not affiliated with or endorsed by the rights holders of the games, artwork or trademarks it lists.
